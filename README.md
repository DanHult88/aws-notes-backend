# AWS Cloud Notes — Backend

The backend for a full-stack notes application I built during an AWS cloud development course.

It's built with Node.js and Express, using PostgreSQL to store the notes. The backend was containerized with Docker and deployed to AWS ECS Fargate, with API Gateway handling HTTPS requests.

I also worked with CodeBuild, ECR, and CodeDeploy to automate the build and deployment process.

The AWS services have since been shut down to avoid ongoing costs, but the code is still available.

**Frontend repository:** [AWS Cloud Notes — Frontend](https://github.com/DanHult88/aws-notes-frontend)
